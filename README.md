# Aplikasi Absensi YAYASAN AL MASYRIFIYAH

Aplikasi manajemen absensi untuk YAYASAN AL MASYRIFIYAH yang dirancang untuk memudahkan pencatatan kehadiran anggota, karyawan, dan peserta kegiatan.

## Fitur Utama

- 📋 Pencatatan absensi real-time
- 👥 Manajemen data pengguna dan kelas
- 📊 Laporan absensi dan statistik kehadiran
- 🔐 Sistem autentikasi dan otorisasi
- 📱 Interface responsif (desktop & mobile)
- 📅 Kalender kehadiran

## Tech Stack

- **Frontend**: React, TailwindCSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT

## Instalasi

```bash
# Clone repository
git clone https://github.com/yantohidayatulloh793-dot/YAYASAN-AL-MASYRIFIYAH.git

# Install dependencies
cd YAYASAN-AL-MASYRIFIYAH
npm install

# Setup environment
cp .env.example .env

# Run aplikasi
npm start
```

## Struktur Folder

```
├── frontend/          # Aplikasi React
├── backend/           # Server Express
├── database/          # Konfigurasi database
└── docs/              # Dokumentasi
```
