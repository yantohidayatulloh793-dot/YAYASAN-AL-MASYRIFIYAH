# Fitur-Fitur Aplikasi Absensi

## 1. Autentikasi & Otorisasi
- ✅ Register user baru
- ✅ Login dengan email & password
- ✅ JWT Token authentication
- ✅ Role-based access control (admin, guru, karyawan, siswa)
- ✅ Password hashing dengan bcryptjs

## 2. Manajemen User
- ✅ Daftar semua user dengan filter
- ✅ Update profil user
- ✅ Delete user (admin only)
- ✅ View detail user
- ✅ Search user by name/email
- ✅ Filter by role

## 3. Manajemen Kelas
- ✅ Create kelas baru (admin only)
- ✅ Edit kelas
- ✅ Delete kelas
- ✅ Assign wali kelas
- ✅ Add/remove siswa dari kelas
- ✅ View jumlah siswa per kelas

## 4. Pencatatan Absensi
- ✅ Catat absensi real-time
- ✅ Multiple status: Hadir, Sakit, Izin, Alpa
- ✅ Keterangan absensi
- ✅ Jam masuk & jam keluar
- ✅ Support geolocation
- ✅ Upload foto absensi

## 5. Laporan Absensi
- ✅ View laporan per kelas
- ✅ Filter by tanggal
- ✅ Statistik kehadiran
- ✅ Group by siswa
- ✅ Export laporan (siap ditambahkan)

## 6. Dashboard
- ✅ Statistik kehadiran
- ✅ Quick access ke semua fitur
- ✅ User profile
- ✅ Responsive design

## 7. Interface
- ✅ Login page
- ✅ Dashboard dengan navigation
- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Form validation
- ✅ Error handling
- ✅ Success notifications
